SQL PRACTICE SET – AWESOME CHOCOLATES DATASET
20 QUESTIONS | EASY → MEDIUM → HARD

Dataset Tables:
1. sales
   Columns: SPID, GeoID, PID, SaleDate, Amount, Customers, Boxes
2. people
   Columns: Salesperson, SPID, Team, Location
3. products
   Columns: PID, Product, Category, Size, Cost_per_box
4. geo
   Columns: GeoID, Geo, Region

Instructions:
- Write SQL queries for all questions.
- Do not modify the underlying data.
- Try to solve each question independently before looking at solutions.
- Questions are arranged from easy to hard.
- Use MySQL syntax where database-specific syntax is required.

Concepts: SUM, AVG, MAX, MIN, aggregation.
